# Repository preferences

Do not add comments to code in this repository. Use clear names and straightforward code instead.

After finishing all edits, build a signed Release update, quit any running Debug copy, install the update into /Applications using the local installer, and launch /Applications/Acouplet.app to test it. Follow [Install and run local changes](Docs/Development.md#install-and-run-local-changes). Confirm that only the installed new build is running and that its executable matches the build. Preserve the installed app's signing team so LDAC and existing permissions continue working.

## Documentation

Project documentation lives in [Docs](Docs/README.md). Start with that index for development, testing, LDAC behavior and research. Add or update documentation there when project behavior or workflows change.
